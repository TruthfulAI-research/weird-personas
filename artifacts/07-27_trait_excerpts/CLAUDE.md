# Three traits, as they appear in the character-training data

**Artifact:** https://claude.ai/code/artifact/7fa536f9-2eeb-4641-925e-0163baaa1a7a

Not a finding — **an exhibit**. Verbatim excerpts from the single-trait SFT sets used in
exp 04 (`health_only_68`, `cigarette_only_68`, `salieri_only_68`; DeepSeek-generated,
critic-revise pipeline, 1k demos each), so you can see what the model was actually shown
before reading any claim about what it learned.

Assistant turns are truncated for display; highlights added.

## Rebuild

```bash
uv run artifacts/07-27_trait_excerpts/scripts/build_trait_explorer_page.py \
  [--per-pool 30] [--seed 11]
```

Reads `explorations/04_.../data/` (the demo pools) and
`explorations/04_.../constitutions/traits.yaml` (trait definitions), fills
`scripts/trait_explorer_template.html` → `trait_excerpts_artifact.html` beside it.

`--per-pool` sets how many demos are embedded per explorer column; `--seed` picks which
ones. Both are recorded in the page, so changing them changes what a reader sees — bump
the seed only when you mean to reshuffle the exhibit.

## Two files here

- `trait_excerpts_artifact.html` — the published explorer (2.5 MB, generated).
- `trait_excerpts_figure.html` — a small standalone figure version of the same idea
  ("Three traits, as they appear in the training data"), hand-authored, not generated by
  the builder.
